- Частотный словарь слов **Условие:** Напиши `wordFreq(words)`, которая вернёт объект частот: `{ слово: количество }`. Регистр учитывается. 

// Вход:
const words = ['кот', 'пёс', 'кот', 'кот', 'пёс'];

// Вызов:
const result = wordFreq(words);

// Ожидаемый результат:
const expected = { 'кот': 3, 'пёс': 2 };

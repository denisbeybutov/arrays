- Пересечение массивов

🏗️ **Условие:** Напиши `intersection(arr1, arr2)`, которая вернёт массив элементов, встречающихся в обоих массивах, без дублей. 

        // Вход:
        const arr1 = [1, 2, 3, 4];
        const arr2 = [3, 4, 4, 5, 6];
        
        // Вызов:
        const result = intersection(arr1, arr2);
        
        // Ожидаемый результат:
        const expected = [3, 4];

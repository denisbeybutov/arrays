- Топ-3 активных по цене

🏗️ **Условие:** даны товары `{ title, price, active }`. Оставить `active`, отсортировать по `price` по убыванию, взять топ-3, вернуть заголовки. 

      // Вход:
      const products = [
        { title: 'A', price: 90, active: true },
        { title: 'B', price: 340, active: true },
        { title: 'C', price: 210, active: false },
        { title: 'D', price: 500, active: true },
        { title: 'E', price: 120, active: true }
      ];
      
      // Выход:
      const result = ['D', 'B', 'E'];

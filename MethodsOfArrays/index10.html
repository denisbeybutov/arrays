- Группировка и сумма по ключу

🏗️ **Условие:** Напиши `groupSumBy(items, groupKey, valueKey)`, которая соберёт объект вида `{[group]: sum}`. 

        // Вход:
        const items = [
          { dept: 'it', amount: 100 },
          { dept: 'sales', amount: 40 },
          { dept: 'it', amount: 60 },
          { dept: 'hr', amount: 20 }
        ];
        const groupKey = 'dept';
        const valueKey = 'amount';
        
        // Вызов:
        const result = groupSumBy(items, groupKey, valueKey);
        
        // Ожидаемый результат:
        const expected = { it: 160, sales: 40, hr: 20 };

- Список email админов

🏗️ **Условие:** дан массив пользователей `{ name, email, role }`. Нужно: 1. оставить только администраторов (`role: 'admin'`); 2. вернуть массив email. 

        // Вход:
        const users = [
          { name: 'Анна', email: 'anna@mail.com', role: 'user' },
          { name: 'Иван', email: 'ivan@mail.com', role: 'admin' },
          { name: 'Оля', email: 'olya@mail.com', role: 'admin' }
        ];
        
        // Выход:
        const result = ['ivan@mail.com', 'olya@mail.com'];

- Лучшие студенты

🏗️ **Условие:** дан массив студентов `{ name, grades }`, где `grades` — массив оценок. Нужно: 1. вычислить средний балл каждого студента; 2. оставить студентов со средним баллом от 4 и выше; 3. вернуть массив имён. 

        // Вход:
        const students = [
          { name: 'Аня', grades: [5, 4, 5] },
          { name: 'Иван', grades: [3, 4, 3] },
          { name: 'Оля', grades: [4, 4, 4] }
        ];
        
        // Выход:
        const result = ['Аня', 'Оля'];

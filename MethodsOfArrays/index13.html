- Отбор лучших фильмов

🏗️ **Условие:** дан массив фильмов `{ title, rating, year }`. Нужно: 1. оставить фильмы с рейтингом от 8; 2. отсортировать их по году (по убыванию); 3. вернуть массив названий. 

        // Вход:
        const movies = [
          { title: 'Фильм A', rating: 7.5, year: 2020 },
          { title: 'Фильм B', rating: 8.3, year: 2022 },
          { title: 'Фильм C', rating: 8.1, year: 2019 }
        ];
        
        // Выход:
        const result = ['Фильм B', 'Фильм C'];

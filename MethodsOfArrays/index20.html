- Сведение транзакций в баланс по типам

🏗️ **Условие:** Напиши `balanceByType(tx, typeKey, amountKey)`, которая вернёт `{ income: sum, expense: sum, total: income - expense }`. Типы могут быть любыми строками, но сумму total считать как `income - expense` (если они есть). 

      // Вход:
const tx = [
  { type: 'income', amount: 1000 },
  { type: 'expense', amount: 300 },
  { type: 'expense', amount: 200 },
  { type: 'income', amount: 500 }
];
const typeKey = 'type';
const amountKey = 'amount';

// Вызов:
const result = balanceByType(tx, typeKey, amountKey);

// Ожидаемый результат:
const expected = { income: 1500, expense: 500, total: 1000 };

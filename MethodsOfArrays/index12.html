- Топ популярных тегов

🏗️ **Условие:** дан массив постов `{ title, tags }`, где `tags` — массив тегов. Нужно: 1. собрать все теги в один массив; 2. посчитать, сколько раз встречается каждый тег; 3. вернуть объект с количеством. 

        // Вход:
const posts = [
  { title: 'JS Basics', tags: ['js', 'frontend'] },
  { title: 'React Hooks', tags: ['react', 'js'] },
  { title: 'CSS Grid', tags: ['css', 'frontend'] }
];

// Выход:
const result = { js: 2, frontend: 2, react: 1, css: 1 };
